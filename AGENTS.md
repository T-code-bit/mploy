# Architecture rules

- Temporary birthday visuals use one shared Nairobi-time activation window and client-side expiry timers, so open pages and future visits return to the normal site at the same deadline.
- Uploaded celebration photos are served through imported Lovable Assets pointers, keeping binary media out of the source repository.
- Job descriptions use a shared rich-text editor and sanitized HTML display with plain-text fallback, preserving formatting across posting, editing, and viewing without allowing executable markup.
